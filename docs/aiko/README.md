# AIKO

## Core Principles

- Evidence First
- Analytics before AI
- Structure before Reasoning
- AIKO derives understanding from facts and context.
- It never presents derived observations as facts.

## Evidence-Based Analytics AI

AIKOは介護・福祉向けのEvidence-Based Analytics AIである。

AIKOはLLMだけで回答を生成しない。

RISEN標準データモデルを根拠として、

- 検索
- 要約
- 集計
- 比較
- 傾向分析
- パターン分析
- 事前対応支援

を行い、職員の意思決定を支援する。
