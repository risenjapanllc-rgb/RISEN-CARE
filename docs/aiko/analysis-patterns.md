# AIKO Analysis Patterns

## 1. 目的

AIKOは自然言語による質問を分析し、その意図（Intent）に応じて適切な分析パターンを実行する。

本ドキュメントでは、AIKOが実行する分析処理を定義する。

分析パターンは質問文ではなく、分析方法によって分類する。

---

# 2. 基本フロー

```
質問

↓

Intent判定

↓

Analysis Pattern決定

↓

Evidence取得

↓

分析

↓

回答
```

---

# 3. Analysis Pattern一覧

| Pattern | 内容 |
|----------|------|
| Search | 検索 |
| Summary | 要約 |
| Aggregation | 集計 |
| Comparison | 比較 |
| Trend Analysis | 傾向分析 |
| Pattern Analysis | パターン分析 |
| Recommendation Support | 事前対応支援 |

---

# 4. Search

目的

記録を検索する。

入力

質問

処理

検索条件生成

↓

データ取得

↓

一覧表示

例

・昨日の記録

・最新の支援記録

・転倒記録

---

# 5. Summary

目的

複数記録を時系列で整理し要約する。

入力

Observation

支援記録

ケース記録

処理

取得

↓

時系列整理

↓

要約

例

・最近の様子

・今週のまとめ

---

# 6. Aggregation

目的

数値を集計する。

代表例

・平均

・件数

・合計

・最大

・最小

・中央値

対象

睡眠

食事

排泄

バイタル

例

・平均睡眠時間

・途中覚醒回数

・食事量平均

---

# 7. Comparison

目的

複数条件を比較する。

例

・先月と今月

・興奮あり・なし

・昼夜比較

・平日休日比較

比較結果として差分を抽出する。

---

# 8. Trend Analysis

目的

時間変化を見る。

例

・睡眠時間は減っているか

・体重推移

・血圧変化

・食事量推移

折れ線や時系列分析に利用する。

---

# 9. Pattern Analysis

目的

共通する特徴を見つける。

例

興奮前

転倒前

夜間覚醒

拒否行動

処理

対象イベント取得

↓

前後データ取得

↓

共通特徴抽出

↓

特徴ランキング

例

興奮前24時間では

・睡眠不足

・夕方

・排便なし

が多い。

---

# 10. Recommendation Support

目的

分析結果から事前対応を支援する。

AIKOは介護方法を決定しない。

回答例

睡眠不足の日は

夕方の状態確認を検討できる可能性があります。

分析結果を基に職員が判断する。

---

# 11. 分析原則

AIKOは

事実

↓

分析

↓

提案

の順で回答する。

提案のみを回答しない。

---

# 12. AIKOが行わないこと

AIKOは

原因を断定しない。

診断しない。

介護方法を決定しない。

医学的判断を行わない。

推測のみで回答しない。
